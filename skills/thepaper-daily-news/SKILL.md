# 澎湃今日重要新闻

## 时间与来源

- 使用当前任务提供的北京时间作为截止时间，范围为今天 00:00 至当前，不采用模型记忆中的“今天”。
- 唯一来源为 `thepaper.cn` 及其子域。搜索使用已配置的 `web_search`（DeepSeek），查询包含 `site:thepaper.cn` 和今天日期；其它网站的搜索结果不得采用。
- 对候选调用 `read_web` 读取正文。优先独立报道，不能只凭搜索摘要或早晚报栏目标题写新闻。
- 核对原文发布机构、发布时间和事件时间。拒绝昨天或更早发布的报道、晚于当前的报道、日期不明、付费或登录限制导致读不到正文的结果。
- 澎湃转载稿保留原始消息来源的归属；不将澎湃号的作者投稿表述为澎湃记者独立证实。
- 今天发布的报道可能描述此前事件，须分开标注。原文只有“17日”等相对表述时保留原话，不猜测完整日期。

## 筛选与合并

- 先识别本次请求的类别。支持 **国内、国际、经济、民生、科技**，可选一个或多个，经济和民生独立筛选。“财经”“金融”按经济处理，“国外”“海外”按国际处理。
- 指定类别时，搜索词、目录标题定位、原文筛选和最终摘要都限定在该范围。比如“今天只看民生”“整理3条国际新闻”“看看经济和科技新闻”；“不要国际，只看民生新闻”需同时排除国际内容。
- **经济**侧重宏观经济、产业、企业经营、金融市场；**民生**侧重就业、收入、社保、医疗、教育、住房、物价、消费权益。依据原文的实际主题分类，不把一般经济报道都当成民生。跨类别事件可同时标注多个实际相关类别，但只计一条。
- 按公共影响和新信息量选取 **1–5 条**。未指定时为综合简报，尽量覆盖 **国内、国际、经济民生、科技**；指定时只交付符合类别的报道，不拿其它类别补齐数量。不是照搬热搜排名。
- 类别只作用于当前请求，不自动改成长期偏好。下一次说“今日新闻汇总”恢复综合简报；普通聊天不继承新闻类别或格式。
- 同一事件的不同角度、续报合并为一条，使用截止时间前的新进展；不重复计数。
- 排除明星私生活八卦、粉圈争执、重复稿、纯情绪观点、无新增事实的争议热帖、广告软文。
- 对预测、市场估计和单方宣称明确写“某机构预计”“某方表示”；未被独立证实的说法不得写成已证实事实。
- 可用原文不足五条时直接交付实际条数；没有可核验新闻时明确说明，不更换到其它媒体凑数。

## 交付给用户

每条包括简短标题、1–2句事实摘要、报道日期或时间、事件时间（无法确定则说明）、澎湃原文链接。自然清楚，不写情绪化评论或无依据的影响推断。

工作台开启新闻核验时，先由程序读取原文并检查证据，再将通过检查的资料交给当前 Agent 汇总；不要重复搜索已经准备好的资料。运行日志保留原文依据、排除原因和来源。

本技能只处理新闻简报。其它问题是否联网由当前 Agent 根据不确定性和时效性判断；需要查询时使用现有 DeepSeek 搜索与适合的平台读取工具。普通聊天不强制联网，不受本技能新闻格式限制。
