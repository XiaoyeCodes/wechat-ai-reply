# 每日财经日报

在 Relay 中使用已授权的 `financial_daily` 工具。运行目录、Python 和输出文件由工作台管理，不填写其他电脑的路径，不要求聊天用户执行命令行。

默认读取 https://xnews.jin10.com/topic/343 的最新一期。可提供预期原文日期 `date=YYYY-MM-DD`；来源日期不匹配时失败，不改标旧新闻。此工具只运行应用内已核验的脚本，不执行导入附件中的任意命令。

流程是采集九项行情、抓取该栏目原文、校验五节正文、生成暖白线条刊头和双栏 PDF、渲染全部 PNG 并校验文字顺序与行情。原始数据、实际采集时间及缺项均保存在本次运行目录；晚于早上执行时不声称是 08:00 快照。没有数据时不补编。

使用工具返回的原版 PDF 和预览，不把简短回复重新排版成日报。不用其他网站的新闻替代本栏目的原文。测试台只预览和下载；生成文件不等于发送成功，实际会话仍由工作台原有的发送和确认机制处理。本技能不创建后台日程或选择其他收件人。

本地维护入口为 `scripts/run_daily.py --workspace <独立输出目录> --standalone`，依赖见 `scripts/requirements.txt`。保留原文、封面、九项行情和完整页面预览，具体内容规范见包内参考文档。人工检查全部 PNG 后才宣称视觉验收完成。
