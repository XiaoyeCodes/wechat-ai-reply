# Codex 账号生图

调用 Relay 已授权的 `generate_image` 工具。服务选择“Codex / ChatGPT 账号生图”，无需 API Key。

- 文生图：`{"prompt":"用户要求的画面","mode":"generate"}`。
- 图生图：`{"prompt":"具体修改要求及需要保留的内容","mode":"edit"}`。不填图片 ID 时使用本轮图片，或当前联系人的近期图片。
- 用户给出多张图片时，根据上下文中的图片 ID 指定 `reference_media_id`；目标不清楚时询问。修改刚生成的图片时使用工具返回的图片 ID。
- 编辑必须把原图交给工具，不能仅根据文字描述重新生成。缺少原图时请用户上传，不降级为文生图。
- 提示词保留用户的主体、画面文字、尺寸或比例意图；改图写清保留的主体、构图等。不要额外改变用户没有要求修改的内容。
- 每次调用生成一张图片。工具返回真实媒体后才说明生成成功。自动回复模式下系统会把图片直接发回原微信会话；辅助模式确认草稿后发送，测试台仅预览下载。生成成功不等于已送达，发送状态以系统核对为准。
- 额度不足、未登录、不支持或超时时如实说明。结果待核对时不自动重试，也不切换到单独计费的 API。

工具执行仍遵循 Agent 的权限和确认设置。此技能只负责图片生成，不执行终端、浏览器或文件操作。
