# 网页与视频阅读

1. 阅读 `references/reading.md` 中的证据规则。
2. 调用 `read_web` 读取用户提供的 URL。B 站链接使用视频读取通道。
3. 只根据工具实际返回的正文或字幕总结。视频只有标题和简介时，说明尚未取得字幕。
4. 用当前 Agent 的语言风格给出简短概括，需要时列出关键内容，并附来源链接。
5. 工具失败时说明原因，请用户提供正文或字幕，不编造内容。

这项技能使用 Agent 已授权的 `read_web` 工具，无需执行本地脚本。
