# Agent 定时任务界面

自动任务页提供「Agent 定时任务」和「联系人关怀」两类入口，默认展示 Agent 定时任务，保留联系人关怀原有编辑和发送规则。

Agent 任务先说明「执行一次、共享结果」，突出当前启用数、符合推送条件的联系人总量。每张任务卡包含名称、Agent、启停状态、执行规则、时区、下次时间、符合资格人数、最后状态，以及编辑、启停、立即运行和执行记录。没有 Agent 时提供创建入口；没有任务时提供清晰的第一步。

新建/编辑弹窗依次填写 Agent、任务名称、执行频率、时间、时区、任务正文。每日与每周自动转换 Cron，保留一次性和自定义 Cron。已绑定且启用的技能可插入提示模板，用户可继续编辑。默认新任务停用，避免保存配置就意外推送。立即运行明确会向实际符合资格的联系人推送，零收件人或停用任务在界面禁用并解释原因。

推送对象提示始终明确：绑定此 Agent、正在监听、AI 自动回复的联系人；发送前再次检查。结果不夹带单个联系人的记忆或称呼；服务运行且未暂停时执行，模型与工具权限沿用 Agent。历史按一次执行展示共享文字/图片及逐联系人投递状态，生成过程和审批可跳到已有运行详情。

沿用现有暖白与绿色系统。任务卡采用清晰标题、状态标签和两列元信息，长正文折叠；窄屏按钮换行、字段单列、历史投递使用列表，避免横向溢出。加载、失败、无数据都给出文字状态及可恢复入口；弹窗具备标题、标签、键盘焦点和底部保存反馈。

API 使用 /api/ai/agent-schedules 系列。未创建真实任务、未向微信发送测试消息。
