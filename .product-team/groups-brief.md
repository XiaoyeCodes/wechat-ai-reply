# 群组监听 G1

用户直接要求为联系人添加群组监听，可指定群中的某个人，在其 @ 后像联系人一样把 Agent 回复发回群内。按此明确指令直接继续开发。

默认规则：指定成员 @ 当前登录微信的群内昵称触发。可配置全部或指定成员、仅 @ 或所选成员发言触发。群目标以当前账号、唯一完整群名、群类型及必要成员核验绑定，内部存储键不冒充微信真实群号。

验收：新增/编辑群规则；消息保存独立验证的发送者和提及证据；未知身份不自动触发；初始历史和无关成员消息不触发或干扰运行；群和成员上下文隔离；文字、图片和技能结果发送原群且继续验证目标；配置切换取消旧运行；原私聊与定时任务回归。

边界：本次未提供具体真实群或成员，不添加或测试任何真实群，不实发消息。公共 Agent 定时任务默认排除群聊，避免扩大发送范围。首版群聊使用本地流程 Agent，保持文字/图片回复；私人关怀及专属联系人电脑授权不自动扩展到群。

分工：总协调负责模型、Store、群资格策略、AI上下文/发送守卫与集成；backend 负责 bridge/runtime 与群UIA证据；frontend 负责static与体验；testing 负责独立产品验收和tests。
