# Agent 定时任务 v1

用户要求：给 Agent 添加定时执行某个任务的功能，例如每日新闻技能；执行完毕后推送给所有监听该 Agent 且开启 AI 自动回复的用户。

确认依据：本聊天中用户直接要求“你给我给Agent添加一个定时功能吧……执行完毕后推送给所有启动该agent监听的，并开启了ai自动回复的用户”。这是足够明确的开发指令，按此范围直接实现。

实现基线：复用 FastAPI、SQLite、现有 AI 工具执行和微信发送队列。新增 Agent 任务独立于已有联系人的关怀日程；一次执行、结果共享、逐收件人记录投递状态。支持一次性及重复定时、编辑停用删除、立即运行、查看历史。现有模型/生图工具权限继续有效。未指定具体 Agent 或推送时间，不擅自创建启用中的真实推送任务。

- AC-01：在 AI 中心的自动任务入口为指定 Agent 创建、编辑、启停和删除定时任务，支持时区及一次性/重复时间。
- AC-02：一次触发只执行一次任务，生成的同一份文字或图片结果供所有目标联系人使用；执行过程可观察，包括工具待审批和失败。
- AC-03：推送仅限绑定该 Agent、listening=true、mode=ai_auto 的联系人；发送前再次检查资格，切换 Agent、关闭监听/自动回复、停用任务或暂停服务后不得发送过期内容。
- AC-04：支持完整文字及生成图片，沿用串行微信发送与发送核对，不能把未发送或不确定状态写成成功。
- AC-05：定时触发与投递记录持久化并去重；重启不重放不确定的投递，不补发大量过期任务；展示下次时间、执行和逐收件人结果。
- AC-06：界面清晰说明推送范围和运行条件，允许立即运行；没有符合条件的联系人、没有 Agent、配置错误时给出有效反馈。
- AC-07：独立测试覆盖目标筛选、同一结果复用、停用/资格变化、文本与图片、并发去重及重启，保留原关怀日程行为。

不包含：宿主 Codex 定时自动化、对公网部署、自动新增联系人或授权、修改模型密钥、测试过程中向真实微信发送消息。
