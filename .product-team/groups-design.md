# 群聊监听界面设计 G1

添加弹窗提供联系人与群聊两类，联系人保留完整备注及微信号核验；群聊填写完整群名，不要求或展示系统内部群绑定 ID 为真实群号。

群聊设置按成员范围、触发方式、本人群内名称组织。成员范围可选所有成员或指定成员；指定成员一行一个，解释使用微信显示的昵称/群内名称。触发方式默认「仅 @ 我」，可选「所选成员发言」。本人群内显示名用于识别 @，留空时说明采用微信检测名称，需与群内昵称一致。添加后可在右侧群聊监听规则中编辑保存。

会话列表和联系人表显示群聊标签；群详情资料显示会话类型，隐藏伪群号。聊天消息显示实际发送成员，未知成员标注未识别，发回原群的文字或图片不承诺真正 @ 某人。群聊暂不参加 Agent 公共定时推送，在定时任务的收件说明和人数中排除。

沿用现有暖白与绿色界面；添加表单可滚动，标题与保存动作保持可见，窄屏字段单列。群规则修改单独保存，背景刷新不覆盖正在填写的规则；错误在原表单显示，保存结果明确提示。

仅在隔离演示测试，不向真实微信群发送消息。
