# 音色清单

`minimax-voices.json` 保存当前选用的 3 个 MiniMax 预设、2 个在线预设，以及 5 个已创建成功的 MiniMax 克隆音色的名称和 `voice_id`。

清单仅用于备份音色标识，不包含 API Key、加密凭证、账号配置、联系人绑定、聊天记录或原始录音。克隆模型存储在 MiniMax 平台，无法随 Git 一起备份；音色可用性和有效期以平台状态为准。

在另一台电脑使用时，先在面板中自行配置创建这些音色的 MiniMax 账号的 API Key，再同步音色。已激活的音色可由平台返回，清单可用于核对 ID 和恢复名称。未激活音色可能暂时不出现在平台查询结果中。此清单不会自动替换联系人的音色，也不会触发克隆、合成或计费。

本机运行数据仍保存在被 Git 忽略的 `.panel-data/` 中。
