# Vendored dependency: pywechat / pyweixin

- Upstream: https://github.com/Hello-Mr-Crab/pywechat
- Original author: Hello-Mr-Crab and upstream contributors.
- Local package metadata: `pywechat127`, version `1.9.8`.
- Included here: the Python source and packaging files in `src/`, plus the original `LICENSE`.

Relay uses `pyweixin` for Windows desktop WeChat UI Automation. The vendored directory is a source snapshot used by this project; it is not represented as the latest upstream release. The download used to initialize this workspace did not retain an upstream commit identifier.

The upstream license text is preserved verbatim in [LICENSE](LICENSE). Its original copyright notices and source headers remain in place. Relay-specific window management, message handling, panel and Agent code live in `../wechat_panel/`.

Upstream screenshots, binary inspection tools, notebooks, local environments and document attachments are not included. For upstream manuals and updates, visit the upstream repository.
