# AI 工作空间的资源归属

## 共享资源

- 设置 / 模型与 API：保存接口、模型与密钥，提供官方 API Key 申请入口和平台预设，Agent 选择使用。
- 扩展中心 / Skills：直接列出已安装技能，Agent 选择绑定。
- 设置 / MCP：直接列出已添加 MCP，发现和导入工具后按 Agent 授权。
- 设置 / 服务配置：搜索、图像、音频、存储等服务的接口与账号。普通 HTTP 服务不混称为 MCP。
- 扩展中心 / 工具与权限：维护工具定义与执行策略，Agent 选择允许调用的工具。
- 知识库：统一维护资料，可供多个 Agent 选用。
- 设置 / 回复设置：全局对话默认值。运行记录在 AI 中心统一查看。

配置资源不等于给所有 Agent 授权。编辑 Agent 时只选择要使用的共享资源和该 Agent 的行为规则。

## 单个 Agent

我的 Agent 卡片提供编辑、记忆与档案、自动任务、测试入口。编辑器保留角色与模型、工具与技能、知识与记忆、回复与关怀、运行设置五类。

记忆与档案、自动任务从对应 Agent 卡片进入，页面显示所属 Agent、返回入口和局部导航。两者不再作为全局共享资源的同级入口。

- 记忆以 Agent + 联系人 / 测试会话隔离；进入后固定 Agent，用户只需选择要查看的联系人。保留历史联系人的查询，不因绑定变更抹去历史。
- 定时任务和联系人关怀只显示当前 Agent 的记录。创建和编辑固定所属 Agent；不再默认选择列表中第一位 Agent。
- 请求返回时校验页面实例与所属范围；离开页面或切换 Agent 后，旧请求不能覆盖新页面。

本次仅整理界面和配置入口，保留已有资源 ID、Agent 绑定、记忆存储和定时执行机制。未迁移、重置或重新授权用户配置。
