# 微信助手多平台读取接入

将 Agent Reach 的16类平台通过四个只读工具接入工作流 Agent：搜索、阅读、浏览，以及明确请求后的音视频转写。
平台及操作均为固定白名单，模型只能提供查询词、公开URL/ID和有限条数，不能提供命令、文件路径或任意执行参数。

公开平台使用现有 CLI/API；需要登录的平台复用用户已有浏览器会话。缺少登录、转写密钥或组件时返回明确失败，绝不把“已接入”当作“已实时验证”。
Aria增加工具和技能绑定，保留提示词、记忆、联系人及其他设置。既有 read_web 对支持的链接转入专用读取器，通用网页仍走原流程。

验证覆盖：参数白名单、URL主机检查、联网关闭、失败/空结果、字幕与简介区分、实际模型工具选择；实时检查只读公开样本。需要人工登录的平台记录待完成项。
