# Agent 编辑页分类

按用户配置任务组织，使用原有字段和授权 ID，切换分类不提交配置。底部“保存配置”统一提交，取消不写入。

| 分类 | 配置内容 |
| --- | --- |
| 角色与模型 | 名称、职责、系统提示词、聊天模型 |
| 工具与技能 | 技能与所需工具、按用途分组的工具授权、搜索服务 |
| 知识与记忆 | 知识库、检索方式、用户长期记忆、保留期限 |
| 回复与关怀 | 图片理解、天气聊天背景、情绪与关系边界、主动关怀时间与频次 |
| 运行设置 | 联网与来源规则、处理流程、调用限制、外部观测与正文传输 |

新闻汇总属于技能，新闻采集属于工具，勾选新闻技能时自动选中新闻采集工具。查天气、音乐、地点和电影归入生活查询工具；自动获取天气作为聊天背景是回复行为，单独配置。联网时机不再和技能开关混排。

技能与工具支持按名称、说明搜索，各组显示已选数量。同一权限只保留一个复选框；勾选内置技能时自动选中已知的可用依赖工具，不再显示第二个添加按钮；统一保存后生效。取消勾选会撤回本次自动添加且其他已选技能不再需要的工具，保留之前已有或手动选择的授权。搜索隐藏项仍参与最终保存。

移除编辑页的“启用 Agent”控件。新建沿用默认启用，编辑保留原有启停状态，避免保存时意外改变运行状态。联系人是否监听、是否自动回复，继续在聊天设置中控制。

Hermes、金融研究和外部 Agent 保留各自运行配置；不适用的本地流程字段不显示，已有值仍随编辑保存。没有改变工具审批策略或后台任务行为。

图片生成与音频文件生成不再在编辑 Agent 中单独展示配置区，使用已有 Skills 与服务配置。旧媒体参数和授权无损保留。「回复与关怀」在图片理解后提供独立的「语音回复」：保存 Agent 默认回复方式、回复音色和 MiniMax 模型，复用音色目录与声音克隆窗口，并支持浏览器试听。默认设置在 Agent 保存时提交；联系人选择「跟随 Agent」才使用默认配置，单独的联系人偏好优先。
