# 声音、视觉与联网配置整理

按当前执行路径整理 Agent 编辑器，延续现有绿色、圆角卡片样式。

- 微信语音按联系人保存；Agent 编辑器复用 MiniMax 配置弹窗，说明音色与 Turbo/HD 的选择位置。旧 TTS 文件生成放入明确标注的高级折叠区，保留已有数据与执行能力。
- 图片理解与图片生成分开。图片理解关闭时收起模型选项；模型留空实际沿用聊天模型。参考图、LoRA 按所选绘图协议显示；历史不兼容值明确提示并允许主动清除。
- 联网策略、搜索连接、来源展示集中在联网栏目。原生 news-aggregator-skill 显示绑定和工具状态，兼容旧新闻核验设置，不将其作为原生 Skill 的开关。
- 显示天气、音乐、地点、电影工具的真实授权与依赖状态；显式点击才能增加授权，取消编辑不写入。天气上下文与按需天气工具分别解释。
- 折叠或切换服务不清空现有配置，不更改角色提示词、记忆、联系人回复方式或密钥。

验证：浏览器检查条件显示、嵌套 MiniMax 弹窗、授权取消/保存、旧配置往返及移动端；复用现有语音和 Agent 编辑器回归测试。无真实远端服务调用与微信发送。

## 后续整理要求

整个编辑器分为基本设定、能力与技能、记忆与关怀、高级设置四页；能力配置与技能/工具授权归在同一页，移除重复的能力总览卡片。每个技能/工具显示用途与执行策略。删除 Agent 来源选择，内部保留现有执行类型，Hermes、金融引擎与外部 Agent 只显示适用配置。所有页共用一个表单，切页与取消不写入，保存保持未展示的数据。
