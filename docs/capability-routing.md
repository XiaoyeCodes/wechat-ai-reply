# 技能筛选与复杂任务

本地流程 Agent 保留完整的已授权快照，执行器仍检查停用状态、联网设置、MCP 触发、参数、审批及任务是否有效。筛选只减少本轮提供给模型的能力，不授予额外权限。

有绑定技能或大型工具集时，先以本轮正文、技能/工具公开元数据及少量已隔离的跟进上下文选择候选。原生引用、网页内容、技能全文不作为新的授权请求。当前最多展示 6 个候选技能和 12 个工具定义，技能全文及附件仍按需加载。小型无技能的现有流程保持兼容。

`search_capabilities` 用于补搜已授权能力；搜索返回摘要，并让相关工具在下一轮出现。它不会执行任务。`use_skill` 实际获批并加载后，相关工具才可进一步扩展；模型在同一轮猜测调用尚未提供的工具时，整批调用会先被拒绝。发现和阅读技能最多 6 轮，实际操作仍受 Agent 原有 `max_tool_rounds` 限制。

技能是专用处理方法，不是执行信息查询的前置条件。没有适用技能、技能停用或只绑定无关技能时，需要外部资料的请求直接提供已授权的 `web_search`，必要时用 `read_web` 阅读原文、继续补查。`search_capabilities` 只在确实缺能力时用于发现，不强制放在普通搜索之前。没有联网权限或搜索实际失败时保持诚实；搜索结果不能代替保存记忆、创建提醒或生成文件的执行凭据。复杂查询缺少天气、电影、音乐或地点专用工具时，也可规划搜索后备，并按实际来源回答。

新闻来源按意图区分：AI热点新闻对应 AIHot 榜单和热度，AI日报/每日AI新闻对应 AI工具集最新一期，每日新闻日报对应 60 秒全球新闻，金十财经日报对应受控财经 PDF 流程，多源聚合对应新闻汇总。明确来源优先，否定提及不触发，多个明确来源分别执行。仅文字要求不会加载生图工具。普通天气优先已授权的内置服务；未授权、停用或失败时可使用已经授权的高德天气，明确要求高德时遵循来源。

网页阅读的既有 DeepSeek 通道失败或未返回正文时，最多使用一次通用阅读器重读同一公开 URL。验证码、摘要、截断正文及读取失败不能作为全文证据，原始 URL 与跳转 URL 分开保留；特殊新闻来源仍先走其专用适配器。

复杂请求至多增加一次结构化规划。计划按工具和已绑定技能校验，拒绝未知 ID、不兼容步骤、循环依赖、漏掉独立请求或必需产物的计划；失败时使用受限回退。计划只约束执行，不主动执行工具或取消审批。运行详情记录候选、工具加载及计划；实际回执更新进度，加载技能、读到错误页面或模型自称完成不算完成。

多个查询共享搜索工具时，结果按步骤领域和目标归属，不能靠调用顺序认领。一轮新闻搜索不能完成天气查询；天气搜索后备还需查询及来源对应所要求的地点。只有真实来源条目可作为搜索证据，接口回显的查询词不算来源内容。

依赖未满足时不会提前生图或提交操作。结果不确定的写操作禁止重复；已完成步骤不因一次补做而重放。所有必需步骤未完成时，纠正一次后收敛为统一失败短句，并抑制部分附件。缺必要信息时只发送澄清文字，不夹带已有图片或 PDF。

复杂任务的独立文字结果与图片、PDF 原子入队，所有部分都取得回执后才记为送达。单纯新闻海报的内部采集/生图步骤不额外发送说明文字。执行完成和实际微信送达仍分别记录。

验证包括 `test_capability_routing.py`、`test_task_planning.py`、`test_routed_conversations.py`、`test_mixed_task_delivery.py` 及既有技能、审批、引用、定时、发送回归。模拟验收必须使用临时数据库和 Demo 发送器，禁止真实微信桥接器；真实服务测试也只在隔离数据中进行。
