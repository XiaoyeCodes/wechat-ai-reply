# 微信原生语音回复

已在 Windows、微信 4.1.15.53 验证：生成中文语音 → 专用播放通路 → 微信原生录音 → 单次发送 → 核对新增的本人语音气泡。微信自己的「语音转文字」也正确识别了测试内容。

已接入 Agent 自动回复队列。在聊天页面右侧「Agent 回复形式」选择「文字回复」或「语音回复」，设置按联系人独立保存，刷新页面和重启后保留。AI 辅助模式仍须先发送草稿；人工输入和操作审批保持文字。

编辑 Agent →「回复与关怀」→「语音回复」可保存默认回复方式、音色和 MiniMax Turbo / HD 模型，选择与联系人侧栏相同的预设或专属音色，并在浏览器试听。这里的音色修改在点击 Agent「保存配置」后生效，取消编辑不修改原配置。MiniMax 连接与克隆窗口共用账号设置；从 Agent 打开时，音色和模型填入当前 Agent 草稿，不会改到背景中的联系人。

联系人选择「跟随 Agent」后，自动回复使用当前绑定 Agent 的默认回复方式与声音；切换 Agent 随之切换。联系人原有的文字 / 语音选择保持独立。跟随期间在微信明确要求文字或语音，会切换为当前联系人的独立偏好；在侧栏单独改音色也会改用独立语音设置。群聊仍只使用文字和图片，公共定时任务不转成语音。

联系人也可以发文字「以后用语音回复我」「开启语音回复」「改回文字回复」「别发语音了」。明确的切换请求即时更新面板，后续回复沿用此选择；引文、转述和假设句不切换设置。此入口切换的是回复方式，不负责识别对方发来的语音。

聊天右侧「声音与试听」可选择并立即保存当前联系人的音色。「在线音色」只提供晓晓（温柔陪伴）、晓伊（元气甜美）。旧联系人已保存的其他音色仍可使用，界面标注为已从候选移除，更换后不再出现在下拉菜单中。阿慧推荐晓晓，语速稍慢。可展开「调整试听文本」比较同一句话，点击「试听音色」只在浏览器播放，不向微信发送，也不切换麦克风。切换联系人或音色会停止旧试听。

在线音色通过 [edge-tts](https://github.com/rany2/edge-tts) 使用 Microsoft Edge 的在线合成服务，不需配置 API Key。本条待朗读的回复或试听文字会提交给该服务；网络或服务不可用时，自动回复改发完整文字，试听明确显示错误，不静默切回机械音。该通道没有本项目提供的可用性保证。原「自动生成语音」仍用于外部 TTS 服务的音频文件，与原生语音选择分开；启用原生语音时不重复合成外部试听音频。

## MiniMax 语音与声音克隆

聊天右侧选择「Agent 回复形式 → 语音回复」，在「声音与试听」点击 **MiniMax 设置与声音克隆**：

1. 保存 MiniMax **中国站** API Key，再点击「检测连接并同步音色」。Key 使用 Windows DPAPI 加密保存，仅返回是否配置，不回显密钥。留空保存保留旧 Key，「清除 Key」会停用该账户的 MiniMax 合成。此处的 Key 专用于原生微信语音，不修改 Agent 的聊天模型或其他外部服务。
2. 从「回复音色」选择三个 MiniMax 预设：漫游少女（`Chinese (Mandarin)_ExplorativeGirl`）、热心女孩（`Chinese (Mandarin)_Warm_HeartedGirl`）、智性少女（`Chinese (Mandarin)_IntellectualGirl`）。同步不会扩充预设选项，账号的克隆、设计音色仍全部显示在「MiniMax 专属音色」中。旧音色保留解析支持，精简菜单不会替换联系人的现有选择。
3. 在 MiniMax 合成模型中选择 **Speech 2.8 Turbo / HD**；音色、模型分别按联系人保存，修改不会清空 Agent 记忆。试听和微信自动语音共用同一接口、音色及语速（0.95）。窗口切换、回复形式切换、音色或模型切换会停止旧试听，发送前重新检查配置，取消已过期的语音。
4. 要克隆声音，在弹窗填写名称并上传自己的或已获授权的单人清晰录音：WAV、MP3 或 M4A，10 秒～5 分钟，最大 20 MB。M4A 需要本机 FFmpeg，提交时转成 WAV。服务端校验真实音频、时长和静音后才上传。原始样音不在本机持久保存，MiniMax 平台会接收样音。
5. 点击「上传并创建音色」。成功后自动定位到弹窗上方的「我的专属音色」，可以直接试听，或点击「设为某联系人的音色」。专属音色也放在聊天侧栏「回复音色」下拉框最前面。创建或试听本身不绑定联系人、不发送微信；明确设为联系人音色时才保存，而且不会切换文字/语音回复模式。尚未激活的本地克隆记录会保留，即使 MiniMax 音色列表暂时不返回它。已创建但列表刷新失败时会提示重新打开窗口，无需再次上传。

**费用（2026-10-18 核对）：** Turbo 2 元、HD 3.5 元／万计费字符，1 汉字计 2 字符。快速复刻 9.9 元／音色，首次正式合成时激活计费；使用克隆音色点击本面板「试听音色」同样会进行正式合成并可能收取激活费，之后另按文本量收费。音色若创建后 7 天内未正式调用，平台会删除该音色。以官方当前价格和账户权限为准。

合成和克隆不自动重试，避免重复费用。克隆请求持久化唯一 ID：重复提交同一请求不会再创建。平台明确拒绝（如 1008 余额不足、2037 样音时长不符、2038 无克隆权限）显示具体原因和错误码，保存为失败；解决原因后重新选择录音再创建。远端超时、服务异常或音色编号重复则保留待核对状态及音色 ID，不推断失败、不再次自动创建。服务出错只显示脱敏信息，不回显远端响应正文或密钥。网络、认证、余额、无效音色等合成故障在开始录音前改发完整文字；录音开始后的发送故障仍遵循不重复发送规则。

音色克隆、Key 和模型设置都只在浏览器中由使用者管理；微信中「改用语音／文字」指令只改变回复形式。没有 Key 时原音色照常可用，MiniMax 试听和克隆入口提示先配置，不替用户充值或生成音色。

当前验收：模拟官方 HTTP 合约已覆盖上传、克隆、Turbo/HD 合成、试听到发送队列、密钥保护、模型切换取消、错误及重放处理；浏览器验证另见测试。没有真实 MiniMax Key 和样音时，不将模拟测试当作真实服务音质或声音相似度验收。

官方接口：[合成](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)、[样音上传](https://platform.minimax.cn/docs/api-reference/file-management-upload)、[克隆](https://platform.minimax.cn/docs/api-reference/voice-cloning-clone)、[音色列表](https://platform.minimax.cn/docs/api-reference/voice-management-get)、[计费](https://platform.minimax.cn/docs/pricing/overview)。

短回复自动合成为一条原生语音。长文、链接、列表、代码保留完整文字；合成失败或超过 50 秒也在开始录音前改发文字，并记录原因。开始录音后若失败、焦点改变或发送结果不确定，则停止并显示状态，不自动补发另一份回复。发出的语音正文保留在聊天记录和 Agent 上下文中，临时 WAV 发送完成后清除。

## 单条诊断脚本

依赖：项目的 Windows Python 环境及 `requirements-voice.txt`；只有离线音色需要安装 Windows 中文慧慧。本机试验使用 Realtek USB Audio 的「扬声器」输出与「立体声混音」录音端。其他声卡、远程桌面及其他微信版本需要单独适配，脚本会先检查设备与控件。

```powershell
.\pywechat-main\.venv\Scripts\python.exe scripts/test-wechat-voice.py --contact-id <工作台联系人ID> --text "你好，这是一条自动语音测试。"
```

脚本默认使用该联系人保存的音色，也可传 `--voice-preset xiaoxiao` 覆盖这次测试。工作台必须在本机 8765 端口运行，联系人已核验。脚本会暂时暂停自动化，操作同一联系人的独立聊天窗口，完成后恢复。一次只发送一条，不会自动重试。现有草稿、焦点变化、录音设备不匹配、空白音频或无法核对录入内容时停止。

测试会临时启用立体声混音、切换录音设备并调整专用通路音量，之后恢复原值。录入音频必须与合成音频的能量变化匹配；微信进程必须实际连接该混音端。发送前不采集实体麦克风。录音无法取消时保留静音混音输入，恢复信息保存在 `.panel-data/voice-route.json`，防止直接切回实体麦克风。

## 当前限制

- 音频输入支持 16 位 PCM WAV、1～50 秒；发送过程中需要微信保持前台焦点。
- 本机 Realtek 的数字输出不会送入立体声混音，已改用实测有效的模拟输出；音量设置会恢复。
- 在线音色与试听使用同一合成参数，音频转换为 16 位 PCM WAV 后进入已核验的微信录音通路。
- 成功标准是新增本人原生语音气泡；这不等同于证明对方已经听过。实际录音时长会包含少量准备时间。

实现入口：`wechat_panel/voice_reply.py`、`wechat_panel/wechat_voice.py`、`WeixinBridge.send_voice()`。所有真实微信发送共用串行工作进程；录音结束发送前再次核对设置、任务和可见新消息。
