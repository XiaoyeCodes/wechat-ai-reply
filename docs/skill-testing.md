# Skill 的本地测试与财经日报

`jin10-financial-daily` 绑定后可使用 `financial_daily` 工具，运行项目 `skills/jin10-financial-daily` 内经过核验的流程。导入附件只供阅读，不获得任意命令执行权限。工具不接受命令或用户指定的输出目录；固定流程抓取原文和九项行情，核对正文、文件校验值与全部页面，再返回原版 PDF 和逐页预览。

安装 `requirements-panel.txt` 中的依赖，并让 `pdftoppm`（Poppler）位于 PATH。当前机器有 Codex 的 Poppler 缓存时也会自动发现它。行情使用实际采集时间，未在 08:00 抓取时不会标成 08:00 快照。修改包内 Python 后须重新审查并更新 `package.json` 的 SHA-256 清单，否则执行会被拒绝。

60 秒新闻、AIHot 和 AI 工具集使用结构化原始来源读取，避免网页代理转写时丢失 JSON、排名、热度或最新一期分组。60 秒接口不可用时只回退到同一发布方对应日期的静态 JSON，并核对实际日期；失败不改用其他新闻凑数。普通网页继续遵循配置的阅读服务。

以下命令使用真实模型与生图服务，但只在全新的本地测试目录中运行：

```powershell
.\pywechat-main\.venv\Scripts\python.exe -X utf8 scripts/test-bound-skills.py --output .panel-data/skill-test-new
```

可用 `--only 每日新闻日报 Ai日报` 选择部分测试。每次须更换输出目录。脚本只复制 AI 配置，不复制联系人和聊天，不启动微信 Runtime；所有运行都是 `dry_run`，额外阻断发送入队方法，并核对消息表为零。图像和 PDF 保存在隔离目录，结果写入 `results.json`；某项执行失败时命令返回非零。真实服务可能消耗已有账号配额，脚本不会自动改用其他计费接口，也不会重试结果待核对的生成操作。

程序完成和文件存在只代表执行检查通过。交付前还需要查看图片及 PDF 的全部页面，核对文字、日期、条目、热度、版式和实际来源，不能仅凭模型说“成功”判断。

任务失败时，私聊和群聊统一回复“我遇到点问题，未能完成该任务。”，不向聊天对象展开脚本、命令、接口、权限、错误码或本机路径。工作台保留具体原因及被拦截的原始回复。此规则同时检查生成答复和待确认草稿，并禁止把失败说明排成 PDF 或携带残留图片交付。测试失败只在面板展示，定时任务失败不广播；已取消或结果待核对的任务不会额外通知或自动重试。

## 工具衔接与会话验收

`tests/test_aria_conversation_tools.py` 使用临时数据库和 Demo 串行发送器验证私聊、群聊的知识、记忆、引用文字与原图、成员隔离、提醒审批和触发、防重复及统一失败回复。真实微信桥接器在测试中被明确禁止。群内个人提醒不借用私聊权限；群公共定时发布由 Agent 定时任务管理。

`tests/test_generated_image_followups.py` 验证已发生成图的续改和看图追问。隐式原图必须属于当前会话、Agent 与群成员，在当前绑定和遗忘边界之后，且消息已核对、原生成任务已发送。历史引用与其他近期图片按消息顺序选择，本轮明确引用始终优先。显式媒体 ID 不能绕过已关联微信消息的未确认、取消或旧绑定边界；未关联消息的本会话合法预览仍可编辑。

`tests/test_reader_skill_context.py` 验证模型直接选择网页、平台或新闻工具时，自动附带唯一已绑定且允许自动加载的技能指南。不扩大工具权限，不绕过确认型技能加载，不以指南里的 URL 冒充实际检索证据，不覆盖已选的专门新闻技能。

`tests/test_weather_tool_coexistence.py` 验证普通天气和高德共存：未指定来源的纯天气问题允许选择任一授权天气工具；实际成功的 Open-Meteo 结果不能被“没有高德回执”覆盖。显式高德及混合地点、路线请求仍需相应专业工具的实际结果。

验收应分别记录接口是否可用、数据是否匹配问题、产物是否完整，以及是否回到原会话。模型说“完成”、任务进入已发送状态或外部接口返回 HTTP 200，都不能单独证明用户任务成功。音乐文章和其他歌曲不是所求曲目，搜索入口不是曲目或播放回执；验证页不是正文，视频简介不是字幕。依赖登录、字幕或转写配置的功能未完成真实调用时，要标注限制，不能统算通过。

`tests/test_automatic_memory_evidence.py` 区分用户自述与一次性任务，禁止从找歌、生成日报等请求推断长期喜好；群聊只移除已核验的本人 @，不把引用或转述存成成员事实。`tests/test_local_query_evidence.py` 验证个人记忆和本地知识查询使用匹配的实际工具回执，不误要求互联网来源，也不让本地回执替代混合问题中的外部事实证据。

`tests/test_memory_forget_receipts.py` 验证遗忘必须取得当前用户相关记录的实际删除凭据，并核对记录已不存在。只口头确认或只检索会得到一次纠正，仍未完成则使用统一失败短句；无关记录、其他成员及其他会话保持隔离，确认不复述已删事实，后续追问不能从旧上下文恢复它们。
