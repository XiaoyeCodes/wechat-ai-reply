# 引用文字与图片问答

在微信私聊或已监听群聊中，引用一条文字或一张图片，再输入自己的问题。Agent 会结合被引用内容回答。群聊仍按本次发言者、成员范围及新问题中的 @ 判断是否触发；原文中的 @ 不触发回复。引用作者可以是其他成员或本人，不会因此读取该作者的私聊或其他群资料。

文字引用与当前问题分别保存和展示。引用里的命令、第一人称、语音偏好和个人事实是讨论资料，不作为新的请求或自动记忆依据。过长引用会标明截短，不补写缺失内容。

图片引用通过这条消息内的引用缩略图打开原生预览，再执行微信的复制操作读取原图，不按“图片”字样查找最近图片替代。需为 Agent 配置图片理解模型。引用消息需在可见区域，桌面微信需能交互；打开的个人图片预览和输入草稿会被保留。原图无法取得或模型失败时明确说明，没有成功识别就不描述图片内容。

原图读取结果按账号、会话、原生消息行、正文和引用缩略图变化记录。群发送者补全导致消息标识变化时，仍保留同一原生引用的读取任务；成功读取可跨工作进程重启复用。录音期间延后读取。复制后的剪贴板和预览窗口按操作归属恢复，不重复打开已读图片。

主动读取仅用于新收到且符合会话触发规则的请求。首次连接、翻看历史和窗口重绘不会启动引用原图或全文复制；已有读取缓存可以被动复用。

可见性按引用缩略图本身检查。微信消息行可能包含越出列表底部的分隔像素，这种情况不应阻止读取仍然完整可见的缩略图。

工作台消息气泡中会显示“引用某人”的文字卡片或图片缩略图，并区分读取中与暂未读取。模型回复仍走原有文字、原生语音、草稿和发送回执流程。回复引用中含微信表情代码时，输入框可能显示为对象；程序复制回读完整文字，只有与待发送内容逐字相符才继续发送。

当前原生读取格式已在 Windows 微信 4.1.15.53 验证。自动化测试使用假 UI、隔离会话及模拟服务；真实模型对话脚本 `scripts/test-quoted-dialogue.py` 不发送微信，需提供已获授权的测试图片。实机记录放在被 Git 忽略的 `.panel-data/reports/`，不能把隔离模型测试当作真实入站消息验收。
