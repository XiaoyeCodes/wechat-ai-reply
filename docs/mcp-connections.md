# 高德和 TreeMind 工具

## 高德

1. 设置 → MCP → 高德地图 MCP → 配置。
2. 填入高德开放平台申请的 **Web 服务 Key**。地址已固定为官方 `https://mcp.amap.com/mcp`，不要把 Key 拼进地址栏。
3. 保存后点“发现工具”，选择需要的工具并导入。
4. 编辑需要使用的 Agent，在“允许调用的工具”中勾选导入的工具；先在测试台验证。

工具输入参数来自服务端真实 `tools/list`。重新导入会更新 Schema，保留已有工具 ID、启用状态和确认策略。不会自动分配给所有联系人。查询类工具默认自动执行，未知远程工具默认确认。禁用服务器 IP 定位联系人。

调用时机：

| 请求 | 行为 |
|---|---|
| 上海明天天气怎么样 | 优先高德天气，不先做普通网页搜索 |
| 附近有什么咖啡店 | 先确认用户城市和位置，再查询；不推测服务器所在位置就是用户位置 |
| 从虹桥到外滩怎么走 | 高德地理编码、路线工具，必要时确认交通方式 |
| 学习路线、今天好累 | 不触发地图工具 |
| 不要联网 | 阻止高德查询 |

打车和导航工具返回的跳转链接不表示已叫车、下单或支付。天气预报超出服务覆盖日期时不能编造。

官方接入资料：https://developer.amap.com/api/mcp-server/gettingstarted

## TreeMind 树图

当前是**待配置入口**。截至本次开发核实，官网确认企业 API/SDK 接入，尚未找到公开、可核实的官方 MCP 地址或 REST API 请求格式，因此没有预填猜测的 URL，也没有生成过真实 TreeMind 作品。

- 若服务商提供 Streamable HTTP MCP 地址：编辑 TreeMind 连接，填写地址/密钥，发现并导入工具。
- 若服务商提供 REST API：AI 中心 → 工具 → `treemind_mindmap`。按其文档填写完整接口地址、方法、认证、输入参数 JSON Schema，然后启用。此预设初始停用，空参数不是 TreeMind 官方协议。
- 当前 HTTP 通用适配器支持 GET 查询参数和 POST JSON、单个 Header 鉴权；若官方接口需要签名、异步任务轮询或其他专用协议，需要按获得的文档补适配器，不能仅凭填入 Key 就声称已接通。
- 将工具绑定给选定的 Agent；只有“生成/整理/修改思维导图”等明确请求才允许调用。“思维导图是什么”不会创建作品。
- 创建默认在面板确认；如果将执行策略改为自动，则按本轮明确的生成请求执行。
- 只有工具成功返回可访问链接，才交付导图链接。响应不明确/超时不重复创建；从运行记录核对外部结果。

官网：https://shutu.cn/

## 验证范围

无服务商凭证时，通过本机模拟 MCP 服务验证真实 SDK 的 initialize、notifications/initialized、tools/list 和 tools/call，不把模拟结果计作高德或 TreeMind 线上验证。API Key 使用 Windows DPAPI 加密保存，不回显到浏览器；请求日志与错误信息脱敏。

2026-10-11 验证：182 项 Python 回归测试、6 项 Playwright 浏览器流程通过；另复查了 401 鉴权失败的日志脱敏。外部厂商线上验证仍需用户提供有效凭证。
