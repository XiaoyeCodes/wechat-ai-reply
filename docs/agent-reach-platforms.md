# Aria 的 Agent Reach 多平台工具

已绑定到现有 Aria，新增 `platform_search`、`platform_read`、`platform_browse`、`platform_transcribe`，配套技能为 `agent-reach-platforms`。
原有提示词、长期记忆、最近对话范围和联系人绑定保留。配置前的数据库备份位于 `.panel-data/backups/before-platform-tools-*.sqlite3`。

## 可以怎样提问

- “帮我在小红书搜咖啡，只给三条笔记和链接。”
- “在 X 上搜 OpenAI 最近的讨论。”
- “总结这个 YouTube 视频：链接。”
- “这个 GitHub 仓库做什么？链接。”
- “读一下这个 RSS：订阅源链接。”
- “看看 V2EX 热门话题。”
- “查一下雪球上 NVDA 的行情。”
- “在 LinkedIn 搜 Python 职位。”（需要可用登录态）
- “把这期小宇宙播客转写出来：链接。”（全文转写需要配置服务）

## 后续补充账号与转写服务

账号平台复用已连接 OpenCLI 扩展的 Chrome。直接在该浏览器中打开对应网站登录；无需把密码或Cookie发到微信，也无需再次改动Aria的工具绑定。

音频转写：在本机终端运行 `agent-reach configure groq-key`，按隐藏输入提示配置自己的Groq密钥。YouTube也支持Agent Reach配置的OpenAI转写服务；小宇宙脚本使用Groq。没有凭证时工具会在下载前停止。转写会把音频发送给相应服务，配额以该服务账户为准。

Boss专用CDP浏览器的启动被自动审批以 `blocked by policy` 拦截，未采用该路线；本项目改为保留现有OpenCLI的只读搜索、详情接口。Boss CLI组件也已安装，但微信Agent不会自动启动调试浏览器或读取Cookie。

## 维护与边界

- 平台和操作为固定白名单，不向模型开放任意Shell、登录、发帖、点赞、私信、投递等操作。
- 本轮关闭联网时，上述平台工具同样关闭。
- 需要字幕的视频先取字幕，再按明确请求使用转写工具；没有正文不会编造摘要。
- 通用 `read_web` 对已支持平台的链接会转入专用读取流程。
- 未把所有平台的所有命令都开放给Aria；仅接入本文列出的查询与阅读能力。
- 可用 `scripts/enable-platform-tools.py --agent Aria` 重新绑定；脚本会备份并校验记忆与联系人设置。
