# Agent 定时任务

在 **AI 中心 → 我的 Agent → 对应 Agent 的定时任务** 中，为一个本地流程 Agent 配置一次性或重复任务。与“联系人关怀”不同，Agent 定时任务在独立上下文中执行一次，然后把同一份结果发布到符合条件的接收会话。

## 配置与使用

1. 为 Agent 配置模型及任务所需技能和工具，例如新闻技能、网页读取、Codex 图像生成服务及工具。
2. 打开“自动任务”，新建 Agent 定时任务，选择 Agent、执行时间、时区和任务内容。支持每日、每周、一次性和自定义 Cron；时区默认 `Asia/Shanghai`。
3. 「发布到」可选所有符合条件的私聊，或指定联系人/群聊。指定时至少勾选一个会话；只有选中的会话会接收。原有任务保留私聊范围，不自动加入群聊。保存后检查时间和接收会话数量，再启用任务。新任务默认停用。
4. 接收联系人或群聊必须同时满足：绑定这个 Agent、开启监听、会话模式为 **AI 自动回复**。人工模式、仅监听和 AI 辅助均不接收此类推送；群聊还需完成群身份核验。
5. 工作台及电脑需保持运行，AI 总开关开启、全部运行未暂停。可以点击“立即运行”提前执行一次；这会真实调用模型和已授权工具，并推送给符合条件的联系人。

例如，每天早上 9 点使用 `0 9 * * *`，任务内容可填写：

> 执行已绑定的“每日新闻·60秒”技能，获取实际日期的最新新闻，按技能规范生成一张9:16手机竖版新闻卡片，保留完整新闻与每日微语。只生成一份公共结果，不使用任何联系人的私人资料或记忆。

图像工具如果配置为“需要确认”，任务会停在待审批状态。在运行记录中确认后继续；定时任务不会取消工具原有审批要求。需要无人值守时，请自行核对并配置该 Agent 的工具权限。

## 执行与推送记录

执行记录区分模型/工具生成过程和每个联系人的投递结果。生成完成不代表微信已送达，只有本机发送核对通过后才显示对应联系人发送完成。图片沿用现有图片发送机制，长文字按微信单条限制分段。短文本按接收会话的回复形式发送文字或原生语音，并使用该会话的音色；不适合朗读的内容或合成失败会保留完整文字。

收件人以任务开始时的名单为基础，发送前再次检查资格；执行中才新绑定的联系人从下一次任务开始接收。关闭监听、切换 Agent 或改为其他会话模式会取消旧投递，即使随后重新开启也不会自动恢复。普通新聊天不会取消公共任务本身。

停用、编辑或删除任务会终止旧执行及未发送的投递。全局暂停、关闭 AI 或停用 Agent 也会阻止发送。一次生成与投递均有持久记录；服务重启不会自动重放旧发送或不确定的工具操作。超过5分钟的错过触发会跳过，生成后的投递有效期为1小时，避免恢复运行后集中推送陈旧内容。

首版支持本地流程 Agent。其他原生执行引擎继续使用各自的会话与权限机制，不在公共定时任务中复用专属联系人的授权。
